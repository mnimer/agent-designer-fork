### REQUIREMENTS & ARCHITECTURE:

1. **Google GenAI SDK & Authentication**:
   - Use the modern SDK imports: `from google import genai` and `from google.genai import types`. Never import deprecated `google.generativeai` or `google.api_core`.
   - For error handling, use `from google.genai.errors import APIError` or standard `except Exception as e:`.
   - Authentication Priority:
     * If `GEMINI_API_KEY` is provided, prioritize it to allow overriding default credentials.
     * Otherwise, fallback to Google Cloud Vertex AI and Application Default Credentials (ADC).
   - Client Initialization:
     ```python
     import os
     from google import genai
     from google.genai import types
     from google.genai.errors import APIError

     class AgentWorkflow:
         def __init__(self, model_name: str = "gemini-2.0-flash"):
             self.model_name = model_name
             self._init_client()

         def _init_client(self):
             api_key = os.getenv("GEMINI_API_KEY")
             project = os.getenv("GOOGLE_CLOUD_PROJECT") or os.getenv("GCP_PROJECT")
             location = os.getenv("GOOGLE_CLOUD_LOCATION") or os.getenv("GOOGLE_CLOUD_REGION") or "us-central1"

             if api_key and api_key.strip():
                 # GEMINI_API_KEY override takes precedence
                 self.client = genai.Client(api_key=api_key.strip())
             elif project:
                 # Cloud Run / Vertex AI with ADC
                 self.client = genai.Client(vertexai=True, project=project, location=location)
             else:
                 # Default Vertex AI initialization
                 self.client = genai.Client(vertexai=True, location=location)
     ```
   - Calling Conventions:
     * When tools are attached: Use `client.chats.create(model=self.model_name, config=config)` and `chat.send_message(user_prompt)` to enable automatic tool execution.
     * When stateless without tools: Use `client.models.generate_content(model=self.model_name, contents=user_prompt, config=config)`.
     * Structured Outputs: Use `types.GenerateContentConfig(system_instruction=self.system_prompt, response_mime_type="application/json", response_schema=ResponseSchema, temperature=0.7)`. Return `response.parsed` (or validated Pydantic model).

2. **File Structure to Generate**:
   - `agent.py`: Core `AgentWorkflow` class orchestrating model configuration, system instructions, tools, memory/session handling, and structured output parsing.
   - `pydantic_models.py`: Pydantic BaseModel schemas for structured outputs (when defined in nodes).
   - `tools/*.py`: Tool definitions (e.g., Google Search, custom functions, MCP tools). Group tools logically by category/source.
   - `server.py`: Production FastAPI server running with Uvicorn:
     * Endpoints:
       - `POST /conversation`: Main conversational endpoint accepting `{"prompt": Optional[str], "message": Optional[str], "messages": Optional[list]}` and returning `{"id": f"conv-{uuid.uuid4()}", "created": int(time.time()), "response": ..., "content": ...}`.
       - `POST /pubsub`: Native Google Cloud Pub/Sub Push Subscription receiver. Decodes base64 message data (`request.message.data`), executes the workflow, and returns HTTP 200 with result status:
         ```python
         class PubSubMessage(BaseModel):
             data: str
             attributes: Optional[Dict[str, Any]] = None
             messageId: Optional[str] = None

         class PubSubPushRequest(BaseModel):
             message: PubSubMessage
             subscription: str

         @app.post("/pubsub", tags=["PubSub Integration"])
         async def pubsub_endpoint(request: PubSubPushRequest):
             try:
                 decoded_bytes = base64.b64decode(request.message.data)
                 user_prompt = decoded_bytes.decode("utf-8")
                 result = workflow.generate(user_prompt)
                 response_data = result.model_dump() if hasattr(result, "model_dump") else str(result)
                 return {"status": "SUCCESS", "result": response_data}
             except Exception as e:
                 raise HTTPException(status_code=500, detail=str(e))
         ```

## ADK Instructions

### Prerequisites for Writing Code
Do NOT write agent code until a project is scaffolded.

1. Verify project: run `agents-cli info` (proceed if config exists).
2. New project: run `agents-cli scaffold create <name>`.
3. Existing code: run `agents-cli scaffold enhance .`.


**Product name mapping:** "Agent Engine" / "Vertex AI Agent Engine" is now **Agent Runtime**. Use `--deployment-target agent_runtime`.

**Ambient / scheduled / event-driven agents:** ADK's `trigger_sources` registers `/apps/{app}/trigger/*` endpoints on the same FastAPI app for **all** targets. On **Cloud Run** / **GKE** these are public HTTP routes you point a Pub/Sub push subscription or Eventarc trigger at; on **Agent Runtime** the same routes are reachable through the Agent Engine `/api` passthrough (e.g. `.../reasoningEngines/v1/{resource}/api/apps/{app}/trigger/pubsub`). Cloud Run remains the simplest target for unauthenticated trigger sources. See /google-agents-cli-adk-code (`references/adk-python.md`, section "12. Event-Driven / Ambient Agents") for the `trigger_sources` pattern.

**OAuth / user consent agents:** Use **Agent Runtime** with Gemini Enterprise for agents that need OAuth 2.0 user consent (e.g., accessing Google Drive, Calendar, or other user-scoped APIs). Cloud Run does not currently support managed OAuth flows. For a worked example, look up OAuth user consent in the topic index in /google-agents-cli-adk-code → `references/samples.md`.
