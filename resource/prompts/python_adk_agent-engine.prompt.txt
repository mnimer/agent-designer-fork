When custom REST API or HTTP tools are tested in `test_agent.py`, mock external network requests (such as `httpx.Client.get`, `httpx.Client.post`, `httpx.get`, or `requests.get`) using `unittest.mock.patch` to guarantee hermetic execution in air-gapped CI runners without incurring DNS or connection timeouts.
   - **Guardrail Shield, Loop & Conditional Delegate Mocking (CRITICAL PYDANTIC V2 & RUNNER RULE)**: `Agent` / `LlmAgent` / `BaseAgent` are Pydantic v2 `BaseModel` classes whose `__delattr__` raises `AttributeError: 'LlmAgent' object has no attribute 'run_async'` when `unittest.mock.patch.object(agent_instance, "run_async", ...)` exits its `with` block! NEVER call `patch.object(agent_instance, "run_async", ...)` on an `Agent` or `BaseAgent` instance, and NEVER call `patch.object(type(sub_agent), "run_async", ...)` (which patches `BaseAgent.run_async` and bypasses any root `BaseAgent` router/guardrail/circuit-breaker!). Instead, mock `LlmAgent._run_async_impl` (`with patch.object(type(sub_agent), "_run_async_impl", new=mock_run):`) or mock the underlying LLM call (`with patch("google.adk.models.google_llm.Gemini.generate_content_async", new=mock_generate):`). Furthermore, ALWAYS execute `root_agent` via `InMemoryRunner(agent=root_agent, app_name="test_app")` (`session = await runner.session_service.create_session(...)`, `async for event in runner.run_async(...)`) — NEVER call `root_agent.run_async(MagicMock())` with a `MagicMock` context (which crashes with `TypeError: object MagicMock can't be used in 'await' expression` when `BaseAgent` awaits `ctx.plugin_manager.run_before_agent_callback`). If unit-testing a custom `BaseAgent` subclass in isolation with a mock `ctx`, call `custom_agent._run_async_impl(ctx)` directly.
   - **External Tool & MCP Mocking**: When external tools (such as BigQuery MCP, REST APIs, or remote A2A endpoints) are invoked in `test_agent.py`, mock network calls (e.g. `patch("httpx.Client.post", ...)` or mocking the tool function directly) to ensure hermetic execution without network latency or timeout errors.
   - **CRITICAL IMPORT RULE IN test_agent.py**:
     * NEVER import typing symbols (such as `AsyncGenerator`, `Generator`, `Any`, `Dict`, `List`, `Optional`, `Union`, `Callable`, `Tuple`) from `unittest.mock`! `unittest.mock` only provides `AsyncMock`, `MagicMock`, `patch`, and `Mock`.
     * ALWAYS import typing symbols directly from `typing` (`from typing import Any, AsyncGenerator, Dict, List, Optional, Union, Callable, Tuple`).
     * When using type annotations in `test_agent.py` (such as mock signatures `async def mock_run(ctx) -> AsyncGenerator[Any, None]:`), ALWAYS import `Any` alongside `AsyncGenerator` (`from typing import Any, AsyncGenerator, Dict, List, Optional`), or place `from __future__ import annotations` at the very top of `test_agent.py`. Omitting `Any` from typing imports when type annotations are evaluated causes an immediate runtime `NameError: name 'Any' is not defined` during pytest collection.
   - **Python Syntax for Multiline `with` Statements**: When generating multi-context manager `with` statements in `test_agent.py` or other Python source files (such as multiple `patch.object(...)` calls), ALWAYS wrap the context expressions in enclosing parentheses: `with (\n    patch.object(...),\n    patch.object(...)\n):` or use explicit backslash line continuation (`\\`). ### Structured Output with Pydantic

> **Warning**: Using `output_schema` disables tool calling and delegation.

**CRITICAL SCHEMA REQUIREMENT RULE (Pydantic v2)**:
When generating Pydantic models (such as in `pydantic_models.py`) for structured output schemas or input schemas:
- Strictly check whether each field is marked as required (`required: true`).
- For ALL required fields—including array/list types and primitive types—declare the field without a default value or with `Field(..., description=...)` (e.g., `key_competitors: List[str] = Field(..., description="...")` or `key_competitors: List[str]`).
- NEVER use `default_factory=list`, `default=[]`, or `default=None` on required fields! In Pydantic v2, setting any default or default_factory excludes the field from `model_json_schema()["required"]`, which causes schema validation and test assertion failures.
- Only fields with `required: false` may specify default values (e.g., `default_factory=list` or `default=None`).

```python
from pydantic import BaseModel, Field
from typing import List, Literal, Optional

class Evaluation(BaseModel):
    grade: Literal["pass", "fail"] = Field(..., description="The evaluation result.")
    comment: str = Field(..., description="Explanation of the grade.")
    recommendations: List[str] = Field(..., description="Required recommendations list without default factory.")
    notes: Optional[str] = Field(default=None, description="Optional notes.")

evaluator = Agent(
    name="evaluator",
    model="gemini-3.7-flash",
    instruction="Evaluate the input and provide structured feedback.",
    output_schema=Evaluation,
    output_key="evaluation_result",
)
```

### Instruction Best Practices & Session State Interpolation (`{state_key?}`)

**CRITICAL ADK STATE INTERPOLATION RULE (PREVENT `KeyError: Context variable not found`)**:
In Google ADK (`google.adk.flows.llm_flows.prompt._instructions_utils`), any `{var_name}` in an `Agent(instruction="...")` string where `var_name` is a valid Python identifier (`var_name.isidentifier()`) is evaluated as a **mandatory** lookup in `invocation_context.session.state[var_name]`. If `var_name` is not yet set in `session.state` (for example, on Iteration 1 of a `LoopAgent` when `algorithm_generator` runs BEFORE `benchmark_evaluator` has produced `evaluation_feedback`, or when an upstream branch was skipped), bare `{var_name}` without a trailing `?` immediately crashes the server with:
`KeyError: "Context variable not found: \`evaluation_feedback\` in agent 'algorithm_generator'."`
- **MANDATORY RULE 1**: Whenever referencing ANY session state variable in `instruction="..."`, ALWAYS include the trailing `?` optional marker: `{state_key?}` (e.g., `{evaluation_feedback?}`, `{candidate_code?}`, `{initial_draft?}`, `{critique_rubric?}`, `{summary?}`, `{data_a?}`). NEVER write bare `{evaluation_feedback}` or `{candidate_code}` without `?`!
- **MANDATORY RULE 2**: In `LoopAgent` (`subAgentPattern: "loop"` or `"debate"`) and multi-stage pipelines, ALSO attach a `before_agent_callback` on the first/generator agent that initializes all `loopStateKeys` and referenced state variables via `callback_context.state.setdefault("<key>", "")` so `session.state` is guaranteed to be populated before Iteration 1!

```python
# ALWAYS use optional {state_key?} with a trailing '?' for dynamic state injection
instruction = """
You are a {role?} assistant.
User preferences: {user_preferences?}

Rules:
- Always use tools when available
- Never make up information
"""
```

## 3. Orchestration with Workflow Agents

Workflow agents provide deterministic control flow without LLM orchestration.

> These are `BaseAgent`-family composites (`SequentialAgent`, `ParallelAgent`, `LoopAgent`). For the new graph-based Workflow API introduced in ADK 2.0, see `references/adk-workflows.md`.

### SequentialAgent

Executes sub-agents in order. State changes propagate to subsequent agents.

```python
from google.adk.agents import SequentialAgent, Agent

summarizer = Agent(
    name="summarizer",
    model="gemini-3.8-flash",
    instruction="Summarize the input.",
    output_key="summary"
)

question_gen = Agent(
    name="question_generator",
    model="gemini-3.8-flash",
    instruction="Generate questions based on: {summary?}"
)

pipeline = SequentialAgent(
    name="pipeline",
    sub_agents=[summarizer, question_gen],
)
```

### ParallelAgent

Executes sub-agents concurrently. Use distinct `output_key`s to avoid race conditions.

```python
from google.adk.agents import ParallelAgent, SequentialAgent, Agent

fetch_a = Agent(name="fetch_a", ..., output_key="data_a")
fetch_b = Agent(name="fetch_b", ..., output_key="data_b")

merger = Agent(
    name="merger",
    instruction="Combine data_a: {data_a?} and data_b: {data_b?}"
)

pipeline = SequentialAgent(
    name="full_pipeline",
    sub_agents=[
        ParallelAgent(name="fetchers", sub_agents=[fetch_a, fetch_b]),
        merger
    ]
)
```

### LoopAgent

Repeats sub-agents until `max_iterations` or an event with `escalate=True`.

```python
from google.adk.agents import LoopAgent

refinement_loop = LoopAgent(
    name="refinement_loop",
    sub_agents=[evaluator, refiner, escalation_checker],
    max_iterations=5,
)
```

For a production LoopAgent with EscalationChecker, BuiltInPlanner, and grounding citations, look it up in the topic index in `references/samples.md`.

## 4. Multi-Agent Systems & Communication

### Communication Methods

1.  **Shared State**: Agents read/write `session.state`. Use `output_key` for convenience.

2.  **LLM Delegation**: Agent transfers control to a sub-agent based on reasoning.
    ```python
    coordinator = Agent(
        name="coordinator",
        instruction="Route to sales_agent for sales, support_agent for help.",
        sub_agents=[sales_agent, support_agent],
    )
    ```

3.  **AgentTool**: Invoke another agent as a tool (parent stays in control).
    ```python
    from google.adk.tools import AgentTool

    root = Agent(
        name="root",
        tools=[AgentTool(specialist_agent)],
    )
    ```

4.  **Task Delegation (ADK 2.0)**: Set `mode` on a sub-agent for structured, schema-typed delegation — the coordinator gets a `request_task_{name}` tool; the sub-agent returns typed output via the auto-injected `finish_task` tool.
    ```python
    from pydantic import BaseModel

    class ResearchOutput(BaseModel):
        summary: str

    researcher = Agent(
        name="researcher",
        model="gemini-3.7-flash",
        mode="task",                        # 'chat' (default) | 'task' | 'single_turn'
        output_schema=ResearchOutput,
        description="Researches a topic.",  # required for delegation
        instruction="Research the topic, then call finish_task.",
    )
    coordinator = Agent(name="coordinator", model="gemini-3.7-flash", sub_agents=[researcher])
    ```
    Modes: `task` (multi-turn, structured I/O) · `single_turn` (autonomous, no user turn). Sub-agents need a `description`; default I/O schemas (`goal`/`background` in, `result` out) are used if none set. Disabled inside graph `Workflow`s.

## 5. Building Custom Agents (`BaseAgent`)

For custom orchestration logic beyond workflow agents.
- **CRITICAL PYDANTIC V2 `BaseAgent` SUBCLASS RULE**:
  `BaseAgent` in `google.adk.agents` inherits from Pydantic v2 `BaseModel` with `extra="forbid"`.
  Therefore, EVERY custom `BaseAgent` subclass (`ConditionalRouter`, `<Name>Router`, `<GateName>ApprovalGate`, `<Name>CircuitBreaker`, `<Name>GuardrailShield`) MUST:
  1. Import `from pydantic import ConfigDict` and declare `model_config = ConfigDict(arbitrary_types_allowed=True, extra="allow")` on the class body.
  2. Inside `__init__(self, ...)`, resolve any local variables first, call `super().__init__(name=name, sub_agents=...)` **FIRST**, and ONLY assign `self.<attr> = ...` **AFTER** `super().__init__(...)` has completed!
  - Setting `self.<attr> = ...` without `extra="allow"` raises `ValueError: "<Class>" object has no field "<attr>"` at startup.
  - Setting `self.<attr> = ...` *before* `super().__init__(...)` raises `AttributeError: '<Class>' object has no attribute '__pydantic_extra__'` at startup.

```python
from google.adk.agents import BaseAgent
from google.adk.agents.invocation_context import InvocationContext
from google.adk.events import Event, EventActions
from pydantic import ConfigDict
from typing import AsyncGenerator

class ConditionalRouter(BaseAgent):
    model_config = ConfigDict(arbitrary_types_allowed=True, extra="allow")

    async def _run_async_impl(
        self, ctx: InvocationContext
    ) -> AsyncGenerator[Event, None]:
        # Read state
        user_type = ctx.session.state.get("user_type", "regular")

        # Custom routing logic
        if user_type == "premium":
            agent = self.premium_agent
        else:
            agent = self.regular_agent

        # Run selected agent
        async for event in agent.run_async(ctx):
            yield event

class EscalationChecker(BaseAgent):
    """Stops a LoopAgent when condition is met."""
    model_config = ConfigDict(arbitrary_types_allowed=True, extra="allow")

    async def _run_async_impl(
        self, ctx: InvocationContext
    ) -> AsyncGenerator[Event, None]:
        result = ctx.session.state.get("evaluation")
        if result and result.get("grade") == "pass":
            yield Event(author=self.name, actions=EventActions(escalate=True))
        else:
            yield Event(author=self.name)
```

### Visual Router Agents (`agentKind: "router"`)

When a workflow node has `agentKind: "router"`, compile it into a custom `BaseAgent` subclass that implements dynamic routing across its configured branches (`routerConfig.branches`):
1. **Evaluation Modes**:
   - `boolean_expression`: Evaluates branch conditions (`conditionExpression`) against session state (e.g. `state.status == 'passed'`).
   - `numeric_threshold`: Compares a numeric metric (`routerConfig.expressionVariable`, e.g. `score`) against `thresholdValue` (e.g. `score >= 0.8`).
   - `llm_classifier`: Evaluates user query intent against branch category descriptions using `gemini-3.7-flash` or keyword classification.
2. **Dynamic Branch Dispatching & Pydantic v2 Initialization**:
   - Declare `model_config = ConfigDict(arbitrary_types_allowed=True, extra="allow")` on the router class, and inside `__init__`, filter `sub_agents = [a for a in [...] if a is not None and getattr(a, "parent_agent", None) is None]` and call `super().__init__(name=name, sub_agents=sub_agents)` BEFORE assigning `self.branches` or any `self.<branch>_agent` attributes! (Filtering `getattr(a, "parent_agent", None) is None` prevents Pydantic `ValueError: Agent already has a parent agent` if the router class is instantiated multiple times in tests.)
   - The router class maps branch IDs to target candidate agent instances: `self.branches = { "branch_id": agent_instance }`.
   - In `_run_async_impl(self, ctx: InvocationContext)`, the router evaluates the condition, looks up the target agent, and delegates execution via:
     ```python
     selected_agent = self.branches.get(selected_branch_id, self.default_agent)
     if selected_agent:
         async for event in selected_agent.run_async(ctx):
             yield event
     ```
   - Always route to the designated fallback branch (`isDefault: true`) if no explicit conditions match.
3. **Structured Input Schema Support**:
   - When `inputSchema` is enabled on the router node, parse and validate incoming session state or payload into `<RouterName>Input.model_validate(...)`.
   - Condition expressions evaluate directly against typed input fields (e.g. `input.urgency > 3`, `input.category == 'billing'`).

### Synthesizer Agents (`agentKind: "synthesizer"`)

When a workflow node has `agentKind: "synthesizer"` (or is configured with `synthesizerConfig` / `structuredOutput`):
1. **Role & Architectural Principle**:
   - Synthesizers aggregate outputs from preceding upstream agents stored in session state (`ctx.session.state`).
   - **CRITICAL ZERO-TOOLS RULE**: In Vertex AI Gemini, `tools` CANNOT be combined with controlled generation (`output_schema`) on the same agent. Therefore, Synthesizer agents MUST ALWAYS have `tools=[]` (or omit the tools argument). Upstream worker/research agents use tools and write intermediate findings to session state (`output_key="..."`); the synthesizer agent reads from state and produces the final structured schema.
2. **Pydantic v2 Schema Generation**:
   - Define a Pydantic v2 `BaseModel` class at top-level before agent instantiation:
     ```python
     from pydantic import BaseModel, Field
     from typing import List, Optional

     class <SynthesizerName>Output(BaseModel):
         summary: str = Field(..., description="Executive summary of aggregated findings")
         key_points: List[str] = Field(default_factory=list, description="Key takeaways")
         confidence_score: Optional[float] = Field(default=None, description="Confidence metric")
     ```
3. **Agent Instantiation**:
   - Instantiate directly via `Agent`:
     ```python
     synthesizer_agent = Agent(
         name="<synthesizer_identifier>",
         model="gemini-3.7-flash",
         instruction="Consolidate and synthesize upstream state outputs into the structured output schema.",
         output_schema=<SynthesizerName>Output,
         tools=[]
     )
     ```
   - Wire as the final agent in a `SequentialAgent` pipeline following parallel or sequential worker agents.

### Human-in-the-Loop (HITL) Approval Gate Agents (`agentKind: "hitl"`)

When a node has `agentKind: "hitl"` (Approval Gate):
1. **Role & Architectural Principle**:
   - Implements a human checkpoint evaluating approval state before high-stakes operations (e.g. commercial loan approval, large fund disbursement, destructive changes).
   - Evaluates `approvalCondition` from state (e.g. `state.get("loan_amount", 0) > 100000 or state.get("risk_tier") == "ELEVATED"`).
   - If human approval is required and neither `approved` in state nor an interactive response is found, pauses workflow execution and requests human intervention (`RequestInput` or `request_input` tool).
   - When human provides approval or application qualifies for auto-approval, dispatches `approved_agent` (e.g. disbursement). When rejected or timed out, dispatches `rejected_agent` (e.g. rejection notice).
2. **Implementation as `BaseAgent` Subclass**:
   ```python
   from google.adk.events.request_input import RequestInput
   from pydantic import ConfigDict

   class <GateName>ApprovalGate(BaseAgent):
       """HITL approval gate evaluating human approval before dispatching downstream agents."""
       model_config = ConfigDict(arbitrary_types_allowed=True, extra="allow")

       def __init__(
           self,
           name: str,
           approved_agent: Optional[Any] = None,
           rejected_agent: Optional[Any] = None,
           approval_condition: Optional[str] = None,
           request_prompt: Optional[str] = None,
           timeout_hours: int = 48,
           auto_reject_on_timeout: bool = True,
           approver_roles: Optional[List[str]] = None,
           tools: Optional[List[Any]] = None,
       ):
           children = [a for a in (approved_agent, rejected_agent) if a is not None]
           super().__init__(name=name, sub_agents=children)
           self.approved_agent = approved_agent
           self.rejected_agent = rejected_agent
           self.approval_condition = approval_condition
           self.request_prompt = request_prompt
           self.timeout_hours = timeout_hours
           self.auto_reject_on_timeout = auto_reject_on_timeout
           self.approver_roles = approver_roles or []
           self.tools = tools or []

       async def _run_async_impl(
           self, ctx: InvocationContext
       ) -> AsyncGenerator[Event, None]:
           state = ctx.session.state

           # Check for human resume inputs
           resume_inputs = getattr(ctx, "resume_inputs", {}) or {}
           interrupt_key = f"{self.name}_approval"
           if interrupt_key in resume_inputs:
               decision = str(resume_inputs[interrupt_key]).strip().lower()
               is_approved = decision in ("approve", "approved", "yes", "true")
               state["approved"] = is_approved
               state["hitl_status"] = "approved" if is_approved else "rejected"
           elif "approved" in state:
               is_approved = bool(state["approved"])
           elif state.get("hitl_status") in ("approved", "rejected"):
               is_approved = state.get("hitl_status") == "approved"
           else:
               # Evaluate approval condition
               requires_approval = False
               if self.approval_condition:
                   try:
                       requires_approval = bool(eval(self.approval_condition, {}, {"state": state, "input": state}))
                   except Exception:
                       requires_approval = True

               if requires_approval:
                   prompt_msg = self.request_prompt or f"Manual underwriter approval required for operation in '{self.name}'."
                   yield RequestInput(interrupt_id=interrupt_key, message=prompt_msg)
                   return
               else:
                   is_approved = True
                   state["approved"] = True
                   state["hitl_status"] = "approved"

           target = self.approved_agent if is_approved else self.rejected_agent
           if target is not None:
               async for event in target.run_async(ctx):
                   yield event
           else:
               verdict_str = "APPROVED" if is_approved else "REJECTED"
               yield Event(
                   source=self.name,
                   content=f"HITL Gate '{self.name}' resolved with {verdict_str}, proceeding with workflow."
               )
   ```
3. **Instantiation**:
   - Instantiate with `approved_agent` and `rejected_agent` targeting candidate agents.

### Fallback & Circuit Breaker Agents (`agentKind: "fallback"`)

When a node has `agentKind: "fallback"`:
1. **Role & Resilience Strategy**:
   - Wraps a primary agent execution with automated error interception, retry with exponential backoff, and circuit breaker failover.
   - If the primary agent throws an exception (e.g. rate limits, 503, RESOURCE_EXHAUSTED, DEADLINE_EXCEEDED, UNAVAILABLE), execution automatically retries with exponential backoff up to `max_retries` before switching to a secondary fallback agent without crashing the workflow.
   - If the fallback agent is also unavailable or fails, returns a graceful static degradation response message.
2. **Implementation as `BaseAgent` Subclass**:
   ```python
   from pydantic import ConfigDict

   class <Name>CircuitBreaker(BaseAgent):
       """Circuit breaker and resilience fallback wrapper with exponential backoff."""
       model_config = ConfigDict(arbitrary_types_allowed=True, extra="allow")

       def __init__(
           self,
           name: str,
           primary_agent: Optional[Any] = None,
           fallback_agent: Optional[Any] = None,
           max_retries: int = 3,
           retry_delay_seconds: float = 2.0,
           caught_error_codes: Optional[List[str]] = None,
           static_fallback_message: Optional[str] = None,
           tools: Optional[List[Any]] = None,
       ):
           super().__init__(name=name)
           self.primary_agent = primary_agent
           self.fallback_agent = fallback_agent
           self.max_retries = max_retries
           self.retry_delay_seconds = retry_delay_seconds
           self.caught_error_codes = caught_error_codes or ["RESOURCE_EXHAUSTED", "503", "DEADLINE_EXCEEDED", "QUOTA_EXCEEDED", "UNAVAILABLE"]
           self.static_fallback_message = static_fallback_message or "Live services currently offline. Advisory generated using fallback model."
           self.tools = tools or []

       async def _run_async_impl(
           self, ctx: InvocationContext
       ) -> AsyncGenerator[Event, None]:
           for attempt in range(self.max_retries):
               try:
                   if self.primary_agent is not None:
                       async for event in self.primary_agent.run_async(ctx):
                           yield event
                       return
                   break
               except Exception as exc:
                   err_str = str(exc)
                   is_caught = any(code in err_str for code in self.caught_error_codes)
                   if is_caught and attempt < self.max_retries - 1:
                       delay = self.retry_delay_seconds * (2 ** attempt)
                       logger.warning(f"Circuit Breaker '{self.name}' attempt {attempt + 1} caught {exc}. Retrying in {delay}s...")
                       await asyncio.sleep(delay)
                       continue
                   logger.warning(f"Circuit Breaker '{self.name}' primary failure: {exc}. Switching to fallback agent.")
                   break

           if self.fallback_agent is not None:
               try:
                   async for event in self.fallback_agent.run_async(ctx):
                       yield event
                   return
               except Exception as fb_exc:
                   logger.error(f"Fallback agent execution failed: {fb_exc}")

           yield Event(
               source=self.name,
               content=self.static_fallback_message
           )
   ```

### Guardrail & Security Shield Agents (`agentKind: "guardrail"`)

When a node has `agentKind: "guardrail"`:
1. **Role & Safety Gating**:
   - Inspects user input or agent intermediate outputs against security policies (prompt injection, PII leak, secrets, toxic content, forbidden topics) before routing to the protected core agent, redacting sensitive data, or escalating to a blocker/audit agent.
   - **Ingress Guardrails (`direction: "ingress"`)**:
     * Inspects incoming user messages or events against `blocked_keywords` (e.g. "bypass system instructions", "ignore previous prompt", "dump memory", "sudo exec") and `regex_patterns` (e.g. SSN `\b\d{3}-\d{2}-\d{4}\b`, MRN `\bMRN-[A-Z]{2}\d{6}\b`, DEA `\b[A-Z]{2}\d{7}\b`).
     * On violation: if `action_on_violation == "block"`, routes execution to `block_agent` (e.g. `security_audit_responder`) or yields an `Event` with `custom_violation_message` (e.g. "Security violation: Input contained unauthorized clinical identifiers or unsafe prompt injection instructions.").
     * If clean: routes execution to `pass_agent` (e.g. `clinical_diagnostic_assistant`).
   - **Egress Guardrails (`direction: "egress"`)**:
     * Sanitizes/redacts outgoing agent responses before returning to the caller.
     * When `action_on_violation == "redact"`, replaces all matches of `regex_patterns` with `redaction_token` (e.g. `"[REDACTED_PATIENT_IDENTIFIER]"` via `re.sub`).
2. **Implementation as `BaseAgent` Subclass**:
   ```python
   import re
   from typing import Any, AsyncGenerator, Dict, List, Optional
   from google.adk.agents import BaseAgent
   from google.adk.events import Event, EventActions
   from google.genai import types
   from pydantic import ConfigDict

   class <Name>GuardrailShield(BaseAgent):
       """Security policy filter and input/output guardrail."""
       model_config = ConfigDict(arbitrary_types_allowed=True, extra="allow")

       def __init__(
           self,
           name: str,
           direction: str = "ingress",
           pass_agent: Optional[Any] = None,
           block_agent: Optional[Any] = None,
           policy_rules: Optional[List[str]] = None,
           regex_patterns: Optional[List[Dict[str, str]]] = None,
           blocked_keywords: Optional[List[str]] = None,
           action_on_violation: str = "block",
           custom_violation_message: str = "Request blocked by security guardrail policy.",
           redaction_token: str = "[REDACTED]",
           tools: Optional[List[Any]] = None,
       ):
           super().__init__(name=name)
           self.direction = direction
           self.pass_agent = pass_agent
           self.block_agent = block_agent
           self.policy_rules = policy_rules or []
           self.regex_patterns = regex_patterns or []
           self.blocked_keywords = blocked_keywords or []
           self.action_on_violation = action_on_violation
           self.custom_violation_message = custom_violation_message
           self.redaction_token = redaction_token
           self.tools = tools or []

       def _check_text_violations(self, text: str) -> bool:
           text_lower = text.lower()
           for kw in self.blocked_keywords:
               if kw.lower() in text_lower:
                   return True
           for pat_obj in self.regex_patterns:
               pattern = pat_obj.get("pattern", "") if isinstance(pat_obj, dict) else str(pat_obj)
               if pattern and re.search(pattern, text, flags=re.IGNORECASE):
                   return True
           return False

       def _redact_text(self, text: str) -> str:
           redacted = text
           for pat_obj in self.regex_patterns:
               pattern = pat_obj.get("pattern", "") if isinstance(pat_obj, dict) else str(pat_obj)
               if pattern:
                   redacted = re.sub(pattern, self.redaction_token, redacted, flags=re.IGNORECASE)
           return redacted

       async def _run_async_impl(
           self, ctx: Any
       ) -> AsyncGenerator[Event, None]:
           # Extract input text from context or session events
           input_text = ""
           if hasattr(ctx, "session") and hasattr(ctx.session, "events"):
               for ev in reversed(ctx.session.events):
                   if hasattr(ev, "content") and ev.content:
                       input_text = str(ev.content)
                       break
           elif hasattr(ctx, "user_content"):
               input_text = str(ctx.user_content)

           if self.direction == "ingress":
               has_violation = self._check_text_violations(input_text)
               if has_violation:
                   if self.block_agent is not None:
                       async for event in self.block_agent.run_async(ctx):
                           yield event
                   else:
                       yield Event(
                           author=self.name,
                           content=types.Content(
                               role="model",
                               parts=[types.Part.from_text(text=self.custom_violation_message)]
                           )
                       )
                   return

               # Clean request: pass to protected core agent
               if self.pass_agent is not None:
                   async for event in self.pass_agent.run_async(ctx):
                       yield event
           else:
               # Egress redaction
               redacted_text = self._redact_text(input_text)
               yield Event(
                   author=self.name,
                   content=types.Content(
                       role="model",
                       parts=[types.Part.from_text(text=redacted_text)]
                   )
               )
   ```

### Evaluator-Optimizer Loop Pattern (`subAgentPattern: "loop"`)

When an agent orchestrates sub-agents with `subAgentPattern: "loop"`:
1. **Topology & Orchestration**:
   - Uses `LoopAgent(name="...", sub_agents=[generator_agent, evaluator_agent], max_iterations=N)` from `google.adk.agents`.
   - **CRITICAL LOOP STATE INITIALIZATION & `{state_key?}` RULE**: On Iteration 1 of a `LoopAgent`, the generator agent runs *before* the evaluator agent has ever executed, so `evaluation_feedback` (and other `loopStateKeys`) do not yet exist in `session.state`!
     * You MUST use optional `{evaluation_feedback?}` and `{candidate_code?}` syntax (with a trailing `?`) inside `instruction="..."` strings — NEVER write bare `{evaluation_feedback}` or `{candidate_code}` without `?`, which raises `KeyError: "Context variable not found: \`evaluation_feedback\` in agent '...'"` on Iteration 1!
     * You MUST ALSO define and attach a `before_agent_callback` (e.g. `init_loop_state`) on the generator agent that initializes all `loopStateKeys` via `callback_context.state.setdefault("evaluation_feedback", "None (initial iteration)")`, `callback_context.state.setdefault("candidate_code", "")`, `callback_context.state.setdefault("iteration_index", 0)`, and `callback_context.state.setdefault("is_solution_accepted", False)`.
   - The generator agent creates or refines code/content and writes to state (e.g. `output_key="candidate_code"` or `output_key="draft"`). If `thinkingBudget` is configured (e.g. 2048), configure `generate_content_config=genai_types.GenerateContentConfig(temperature=..., thinking_config=genai_types.ThinkingConfig(thinking_budget=2048))`.
   - The evaluator agent audits candidate code against acceptance criteria (using `code_executor=BuiltInCodeExecutor()` if `code_execution` tool is attached) and writes structured review to `output_key="evaluation_feedback"` / `output_key="critique"`.
   - **Early Termination & Escalation**: If criteria pass or benchmark threshold is met on Iteration 1 (after the generator runs once and the evaluator calls its tool once), the evaluator (or `EscalationChecker`) MUST immediately yield `Event(author=self.name, actions=EventActions(escalate=True))` to break the loop right away so it does not wastefully repeat iterations 2..N.
     * **CRITICAL**: In `EscalationChecker`, NEVER write naive `"fail" not in feedback` checks, because passing benchmark summaries routinely say `"0 failures"` or `"without failure"`! Instead check for explicit failure indicators (`not any(neg in feedback for neg in ("not passed", "passed: false", '"passed": false', "status: fail"))`) when `"pass"` or `"optimal"` is present in `feedback`. The loop is guaranteed to terminate on Iteration 1 when passed, or when `max_iterations` is reached.

### Multi-Agent Debate & Consensus Pattern (`subAgentPattern: "debate"`, `debateConfig`)

When a workflow implements a debate topology:
1. **Topology & Roles**:
   - **Debater Agents (Pro & Con Advocates)**: Formulate contrasting perspectives or affirmative/counter arguments. When web search is enabled, each debater configures `GoogleSearchTool(bypass_multi_tools_limit=True)` and writes arguments to its dedicated state key (e.g. `output_key="pro_arguments"` and `output_key="con_arguments"`). Any reference to `{pro_arguments?}` or `{con_arguments?}` in `instruction` MUST include the trailing `?` optional marker.
   - **Debate Moderator & Arbiter / Consensus Judge**: Moderates multi-round structured debate turns up to `maxRounds` (e.g. 3), evaluates citations, and scores consensus convergence against `consensusThreshold` (e.g. 0.85).
   - **Consensus Resolution Synthesizer (`agentKind: "synthesizer"`)**: Reads accumulated arguments from session state (`{pro_arguments?}`, `{con_arguments?}`) and synthesizes an evidence-backed final resolution.
2. **Implementation in ADK**:
   - Orchestrate debaters and moderator in a round loop or sequential pipeline:
     ```python
     debate_stage = ParallelAgent(
         name="debate_perspectives",
         sub_agents=[pro_advocate, con_advocate]
     )
     debate_rounds_loop = LoopAgent(
         name="debate_rounds_loop",
         sub_agents=[debate_stage, debate_moderator_arbiter],
         max_iterations=3  # from debateConfig.maxRounds
     )
     root_agent = SequentialAgent(
         name="policy_debate_system",
         sub_agents=[debate_rounds_loop, consensus_resolution]
     )
     ```
     Or compose as `SequentialAgent(name="debate_system", sub_agents=[ParallelAgent(name="debate_arguments", sub_agents=[pro_advocate, con_advocate]), debate_moderator_arbiter, consensus_resolution])`.

### Review & Critique Triad Pattern (`subAgentPattern: "review_critique"`)

When a workflow implements a review & critique triad:
1. **Topology**:
   - Three-stage sequential pipeline (`SequentialAgent(sub_agents=[drafter_agent, critic_agent, reviser_agent])`):
     1. **Drafter**: Generates baseline content and writes to `output_key="initial_draft"`.
     2. **Critic**: Analyzes the draft for errors and improvements, writing to `output_key="critique"`.
     3. **Reviser / Synthesizer**: Ingests both `{initial_draft?}` and `{critique?}` from session state and produces the final polished deliverable: `output_key="final_output"`.

### Agent-as-a-Tool Pattern (`builtin_agent_as_tool` / `agent_as_tool`)

When an agent exposes another agent as a callable function tool:
1. **ADK Implementation**:
   - Prefer direct instantiation using `google.adk.tools.agent_tool.AgentTool`:
     ```python
     from google.adk.tools.agent_tool import AgentTool
     generate_sql_query = AgentTool(agent=nl2sql_expert_agent)
     ```
   - If wrapping in a custom function tool, do NOT invoke synchronous `runner.run(question)` because Google ADK's `Runner` does not implement a synchronous `.run()` method (it will raise an `AttributeError`). Instead, declare an async tool function that awaits `runner.run_async`:
     ```python
     async def generate_sql_query(question: str) -> str:
         """Translates natural language questions into performant BigQuery SQL and explains query plan."""
         runner = Runner(agent=nl2sql_expert_agent)
         result = await runner.run_async(question)
         return str(result)
     ```
   - Wire `generate_sql_query` directly into the calling coordinator agent's `tools`:
     ```python
     coordinator_agent = Agent(
         name="coordinator_agent",
         model="gemini-3.7-flash",
         instruction="Decompose user requests and delegate specialized SQL queries using generate_sql_query.",
         tools=[generate_sql_query]
     )
     ```
   - If the calling agent also connects to a Google Cloud Remote MCP Server (e.g. BigQuery Remote MCP), instantiate `McpToolset` with `StreamableHTTPConnectionParams` and `header_provider` with `fetch_id_token(Request(), MCP_SERVER_URL)`, and include both tools:
     ```python
     tools=[bigquery_mcp, generate_sql_query]
     ```
   - In `test_agent.py`, mock `generate_sql_query` or the sub-agent's `run_async` so that test assertions evaluate offline without live database or cloud network latency.

def search_database(

### Human-in-the-Loop (pause & resume)

Pause a run to ask the user something, then resume. This is a general runtime feature (not workflow-specific). Enable resumption at the app level:

```python
from google.adk.apps import App, ResumabilityConfig

app = App(name="my_app", root_agent=root_agent,
          resumability_config=ResumabilityConfig(is_resumable=True))
```

- **Let the model ask:** add the built-in `request_input` tool (`from google.adk.tools import request_input`) to `tools=` — the model calls it when it needs clarification.
- **Approval gate inside a tool:** `tool_context.request_confirmation(hint="Approve this transfer?")`, or `FunctionTool(fn, require_confirmation=...)` (above).
- **Custom long-running tool:** wrap a function with `LongRunningFunctionTool(fn)` to pause until an external result arrives.

The user's reply is read from `ctx.resume_inputs` (available on `ToolContext` and `CallbackContext`). Inside graph workflows the same mechanism is node-based — see `adk-workflows.md` §7.

# Google Workspace Remote MCP Servers (`category === 'google_workspace_mcp'`, `workspace_mcp_*`, `https://*mcp.googleapis.com/mcp/v1`)
# Google Workspace Remote MCP Servers (gmailmcp.googleapis.com, drivemcp.googleapis.com, docsmcp.googleapis.com,
# sheetsmcp.googleapis.com, slidesmcp.googleapis.com, calendarmcp.googleapis.com, chatmcp.googleapis.com,
# meetmcp.googleapis.com, tasksmcp.googleapis.com, people.googleapis.com, formsmcp.googleapis.com,
# keepmcp.googleapis.com, classroommcp.googleapis.com) are USER-SCOPED APIs and must act on behalf of the calling user.
# They use `McpToolset` with `StreamableHTTPConnectionParams` and a caller-aware `header_provider` that inspects
# ADK's `ReadonlyContext` (`ctx`) on every tool call in strict priority order:
#   1. Per-Caller OAuth 2.0 Bearer Token in `ctx.session.state` (`tokenStateKey`, default `"user_access_token"` or `"workspace_access_token"`)
#   2. Domain-Wide Delegation subject impersonation (`credentials.with_subject(caller_email)`) using `ctx.session.state.get("user_email")`, `ctx.session.user_id`, or `subject_email`
#   3. Local Workstation ADC Fallback (`google.auth.default(scopes=scopes)`) from `gcloud auth application-default login`
import os
from typing import Any, Optional
import google.auth
from google.auth.transport.requests import Request
from google.adk.tools.mcp_tool import McpToolset
from google.adk.tools.mcp_tool.mcp_session_manager import StreamableHTTPConnectionParams

# Normalize HTTP 401/403 status on valid JSON-RPC 2.0 responses from *.googleapis.com/mcp
# (Google ESF returns HTTP 403 alongside valid JSON-RPC result/isError payloads when scopes are missing)
for _httpx_mod_name in ("httpx2", "httpx"):
    try:
        _httpx_mod = __import__(_httpx_mod_name)
        _orig_httpx_send = _httpx_mod.AsyncClient.send
        def _make_mcp_send(_orig):
            async def _mcp_jsonrpc_send(self, request, *args, **kwargs):
                resp = await _orig(self, request, *args, **kwargs)
                if resp.status_code in (401, 403) and ".googleapis.com/mcp" in str(getattr(request, "url", "")):
                    if resp.headers.get("content-type", "").lower().startswith("application/json"):
                        resp.status_code = 200
                return resp
            return _mcp_jsonrpc_send
        _httpx_mod.AsyncClient.send = _make_mcp_send(_orig_httpx_send)
    except Exception:
        pass

def get_workspace_mcp_headers(
    ctx: Optional[Any],
    scopes: list[str],
    token_state_key: str = "user_access_token",
    subject_email: Optional[str] = None,
) -> dict[str, str]:
    """Resolves OAuth 2.0 Bearer credentials acting on behalf of the calling user with ADC fallback."""
    headers: dict[str, str] = {}
    user_project = os.environ.get("GOOGLE_CLOUD_PROJECT") or os.environ.get("GOOGLE_CLOUD_PROJECT_ID")
    if user_project:
        headers["X-Goog-User-Project"] = user_project

    # 1. Check if the calling user's OAuth 2.0 access token was passed in ADK state
    # (Gemini Enterprise / Vertex AI AdkApp injects `request.authorizations` as `temp:<auth_id>` in `ctx.state`)
    state = getattr(ctx, "state", None) or getattr(getattr(ctx, "session", None), "state", None) or {}
    caller_token = (
        state.get(token_state_key)
        or state.get(f"temp:{token_state_key}")
        or state.get("user_access_token")
        or state.get("temp:user_access_token")
        or state.get("workspace_access_token")
        or state.get("temp:workspace_access_token")
    )
    if not caller_token and hasattr(state, "items"):
        for _k, _v in state.items():
            if isinstance(_k, str) and (
                _k.startswith("temp:")
                or "oauth" in _k.lower()
                or "access_token" in _k.lower()
            ):
                if isinstance(_v, str) and _v.strip():
                    caller_token = _v.strip()
                    break
                elif isinstance(_v, dict) and isinstance(_v.get("access_token"), str):
                    caller_token = _v["access_token"].strip()
                    break
    if not caller_token:
        caller_token = os.environ.get("WORKSPACE_USER_ACCESS_TOKEN")

    if caller_token:
        token_str = str(caller_token).strip()
        headers["Authorization"] = token_str if token_str.lower().startswith("bearer ") else f"Bearer {token_str}"
        return headers

    # 2. Fallback to Google Auth credentials (with optional Domain-Wide Delegation subject impersonation)
    credentials, _ = google.auth.default(scopes=scopes)
    session_user_id = getattr(ctx, "user_id", None) or getattr(getattr(ctx, "session", None), "user_id", None)
    resolved_subject = (
        state.get("user_email")
        or (session_user_id if isinstance(session_user_id, str) and "@" in session_user_id else None)
        or subject_email
    )
    if resolved_subject and hasattr(credentials, "with_subject"):
        credentials = credentials.with_subject(resolved_subject)
    if not credentials.valid:
        credentials.refresh(Request())
    headers["Authorization"] = f"Bearer {credentials.token}"
    return headers

# Example: Gmail Remote MCP Toolset (configured with scopes from workspaceConfig.scopePreset and caller identity)
workspace_toolset = McpToolset(
    connection_params=StreamableHTTPConnectionParams(
        url="https://gmailmcp.googleapis.com/mcp/v1",
        timeout=30,
    ),
    header_provider=lambda ctx: get_workspace_mcp_headers(
        ctx,
        scopes=["https://www.googleapis.com/auth/gmail.readonly"],
        token_state_key="user_access_token",
    ),
)

# Databricks Managed MCP (Genie Space, Vector Search, Unity Catalog, SQL)
# When Databricks MCP tools are attached (databricksConfig / databricks_mcp_*),
# connect over Streamable HTTP with DATABRICKS_TOKEN Bearer auth.

        headers={"Authorization": f"Bearer {os.environ.get('DATABRICKS_TOKEN', '')}"},
    ),
)

# Snowflake Managed & Cortex MCP (Analyst, Search, Agent, SQL, Generic)
# When Snowflake MCP tools are attached (snowflakeConfig / snowflake_mcp_*),

### State Prefixes

# User-persistent (across sessions)

### Initial Session State Pre-loading (`data/initial_session_state.json`, TASK-215)

When initializing new sessions or test harness scenarios, check if `data/initial_session_state.json` exists relative to the package root. If present, load its JSON dictionary and pass it as `initial_state` or merge into `session.state`:

```python
import json
from pathlib import Path

def load_initial_session_state() -> dict:
    state_path = Path(__file__).resolve().parent / "data" / "initial_session_state.json"
    if state_path.is_file():
        try:
            with open(state_path, "r", encoding="utf-8") as f:
                return json.load(f)
        except Exception as e:
            logging.getLogger(__name__).warning("Failed to load initial session state: %s", e)
    return {}

# Pass to session creation:
session = await session_service.create_session(
    app_name=APP_NAME,
    user_id=user_id,
    session_id=session_id,
    state=load_initial_session_state(),
)

### Artifacts (File Storage)

Store and retrieve binary data (PDFs, images, audio) scoped to session or user:

    await tool_context.save_artifact("user:profile.png", part)           # user-scoped

#### Memory Bank (Long-term Memory)

Managed cross-session memory that persists user preferences, remembers facts across sessions, and learns from conversations over time. See the [`cross-session-memory` recipe](https://github.com/google/adk-samples/tree/main/core/python/cross-session-memory) for a complete implementation.

    ...,

# a subset of events, which is better for incremental processing.

    """Sends the session's events to Memory Bank for memory generation."""
    await callback_context.add_session_to_memory()
    return None
```

### Context Caching

Cache large context windows (system prompt + docs) to reduce latency and cost. Transparent to agent code.

```python
from google.adk.apps import App
from google.adk.agents.context_cache_config import ContextCacheConfig

app = App(
    name="my_app",
    root_agent=root_agent,
    context_cache_config=ContextCacheConfig(
        min_tokens=2048,     # only cache if context exceeds this
        ttl_seconds=1800,    # cache lifetime (default 1800)
        cache_intervals=10,  # re-cache every N invocations
    ),
)
```

### Context Compaction

Prevent context overflow on long sessions by compacting older events into summaries. Use **token-based** compaction: it triggers on actual prompt-token volume, so it handles unpredictable inputs (pasted code, large tool results) better than a fixed turn count.

```python
from google.adk.apps import App
from google.adk.apps.app import EventsCompactionConfig
from google.adk.apps.llm_event_summarizer import LlmEventSummarizer
from google.adk.models import Gemini

app = App(
    name="my_app",
    root_agent=root_agent,
    events_compaction_config=EventsCompactionConfig(
        token_threshold=32000,   # compact once prompt tokens reach this
        event_retention_size=5,  # keep the last 5 raw events un-compacted
        # Optional: custom summarizer model
        summarizer=LlmEventSummarizer(llm=Gemini(model="gemini-3.7-flash")),
    ),
)
```

### App Name

The `App(name=...)` parameter **must match the agent directory name** (default: `app`). A mismatch causes "Session not found" errors during evaluation because the runner infers the app name from the directory path.

```python
# CORRECT — matches the "app" directory
app = App(name="app", root_agent=root_agent)

# WRONG — causes eval failures
app = App(name="my_custom_agent", root_agent=root_agent)
```

**CRITICAL: `App` Keyword Arguments**: In `google.adk.apps.App`, strict Pydantic validation is enabled (`extra='forbid'`). `App(...)` only accepts `name`, `root_agent`, `root_node`, and config objects (`plugins`, `resumability_config`, etc.). NEVER pass `description="..."` to `App(...)` (unlike `Agent`, `App` does NOT have a `description` field and doing so causes immediate Pydantic validation crashes).

## 10. Plugins

Global callback hooks across all agents/tools/LLMs. Use for cross-cutting concerns (logging, guardrails); use callbacks for per-agent logic.

```python
from google.adk.plugins.base_plugin import BasePlugin
from google.adk.apps import App

class MyPlugin(BasePlugin):
    async def before_model_callback(self, *, callback_context, llm_request):
        return None  # return None to observe, return value to intervene

# Register via App — plugins run BEFORE agent-level callbacks
app = App(name="my_app", root_agent=root_agent, plugins=[MyPlugin()])
runner = Runner(app=app, session_service=...)
```

Built-in plugins: `ReflectAndRetryToolPlugin` (retry failed tools), `BigQueryAgentAnalyticsPlugin` (log to BQ), `ContextFilterPlugin` (reduce context size), `GlobalInstructionPlugin` (shared system prompt), `SaveFilesAsArtifactsPlugin`, `LoggingPlugin`, `DebugLoggingPlugin`, `MultimodalToolResultsPlugin`.

Hooks: `before/after_agent_callback`, `before/after_model_callback`, `before/after_tool_callback`, `on_model_error_callback`, `on_tool_error_callback`, `on_user_message_callback`, `before/after_run_callback`, `on_event_callback`. [Full docs](https://adk.dev/plugins/index.md)

### Safety Guardrails

Use `before_model_callback` to filter input or `after_model_callback` to filter output. Return `None` to pass through, or return a modified `LlmResponse` to block/replace. Evaluate with the `safety` metric. [Full docs](https://adk.dev/safety/index.md)

### Consuming a remote A2A agent (CRITICAL RULES)
CRITICAL ADK RULES:
1. `RemoteA2aAgent` is imported ONLY from `google.adk.agents.remote_a2a_agent import RemoteA2aAgent`.
2. NEVER import `google.adk.auth.google_iam_auth` or `google.adk.auth.auth_credential` — these modules DO NOT EXIST in ADK.
3. NEVER pass `auth_credential=`, `custom_headers=`, or `output_key=` to `RemoteA2aAgent(...)` — these parameters DO NOT EXIST on `RemoteA2aAgent`.
4. NEVER write `App.ResumabilityConfig(...)`. `App` is a Pydantic model and does not expose `ResumabilityConfig` as an attribute. Always import it at top-level: `from google.adk.apps import App, ResumabilityConfig` and write `resumability_config=ResumabilityConfig(is_resumable=True)`.
5. When `a2aConfig.rawJsonPack` is provided in the workflow node, emit a `<agent_name>_agent_card.json` file containing the JSON card payload, and pass its path to `agent_card=`:
   ```python
   from pathlib import Path
   from google.adk.agents.remote_a2a_agent import RemoteA2aAgent

   card_path = str(Path(__file__).parent / "<agent_name>_agent_card.json")
   remote_agent = RemoteA2aAgent(
       name="<agent_name>",
       description="...",
       agent_card=card_path,
   )
   ```
6. When connecting to Google Cloud A2A endpoints (e.g. `*.googleapis.com`, Cloud Run endpoints requiring Google Cloud authentication, or when `authType: "google_iam"` with `targetAudience` is configured):
   - Securely generate OIDC Identity Tokens by importing from `google.auth.transport.requests import Request` and `google.oauth2.id_token import fetch_id_token`:
   ```python
   import os
   import httpx
   from google.auth.transport.requests import Request
   from google.oauth2.id_token import fetch_id_token
   from google.adk.agents.remote_a2a_agent import RemoteA2aAgent

   target_audience = os.getenv("A2A_TARGET_AUDIENCE", "https://catalog-service.vendor-corp.internal")
   try:
       token = fetch_id_token(Request(), audience=target_audience)
       headers = {"Authorization": f"Bearer {token}"}
   except Exception:
       headers = {}

   # Disable persistent keepalive connections so pooled sockets are not reused across closed asyncio event loops
   limits = httpx.Limits(max_keepalive_connections=0)
   httpx_client = httpx.AsyncClient(headers=headers, timeout=45.0, limits=limits)

   remote_agent = RemoteA2aAgent(
       name="<agent_name>",
       description="...",
       agent_card=card_path,
       httpx_client=httpx_client,
   )
   ```
   - In `tools.py`, if client functions/tools are generated for A2A JSON-RPC 2.0 communication (e.g. `query_vendor_catalog_a2a`), import `from google.auth.transport.requests import Request` and `from google.oauth2.id_token import fetch_id_token` to fetch and attach the OIDC Bearer token in the `Authorization` header, and execute JSON-RPC 2.0 calls (`{"jsonrpc": "2.0", "method": ..., "params": ..., "id": ...}`) with explicit `timeout=45.0` and retry logic.

## 12. Event-Driven / Ambient Agents

Ambient agents process events (Pub/Sub, Eventarc, schedules) autonomously. ADK provides built-in trigger endpoints that handle payload decoding, session creation, concurrency, and retries.

> **Deployment:** `trigger_sources` registers `/apps/{app}/trigger/*` on the standard FastAPI app, so it works on **all** targets. On **Cloud Run** / **GKE** the endpoints are public HTTP routes you point a Pub/Sub push subscription or Eventarc trigger at. On **Agent Runtime** the same routes are reachable through Agent Engine's `/api` passthrough (`https://{location}-aiplatform.googleapis.com/reasoningEngines/v1/{resource}/api/apps/{app}/trigger/pubsub`). When deployed as a container, `adk api_server` enables trigger endpoints via `--trigger_sources "pubsub,eventarc"`.

```python
from google.adk.cli.fast_api import get_fast_api_app

app = get_fast_api_app(
    agents_dir=AGENTS_DIR,
    web=False,
    trigger_sources=["pubsub", "eventarc"],  # enables /apps/{app}/trigger/pubsub and /apps/{app}/trigger/eventarc
)
```

```bash
# CLI equivalent for local dev
adk api_server --trigger_sources "pubsub,eventarc" path/to/your/agent
```

Trigger endpoints handle: base64 decoding, CloudEvent parsing, per-event session creation (UUID), concurrency semaphore, and exponential backoff on transient errors.

| Setting | Default | Environment Variable |
|---------|---------|----------------------|
| Max concurrent invocations | 10 | `ADK_TRIGGER_MAX_CONCURRENT` |
| Max retry attempts | 3 | `ADK_TRIGGER_MAX_RETRIES` |
| Base backoff delay | 1.0s | `ADK_TRIGGER_RETRY_BASE_DELAY` |
| Max backoff delay | 30.0s | `ADK_TRIGGER_RETRY_MAX_DELAY` |

Sessions are ephemeral by default (`InMemorySessionService`); use `DatabaseSessionService` for audit trails. Pub/Sub and Eventarc have a 10-minute processing limit. For non-GCP sources, use `adk api_server --auto_create_session` with the `/run` endpoint instead.

**Scheduled / cron execution:** Use Cloud Scheduler to publish to a Pub/Sub topic on a cron schedule, then connect the topic to the agent's `/apps/{app}/trigger/pubsub` endpoint. This is how you implement "run daily at 8 PM" — no custom scheduling code needed.

Since ambient agents have no interactive user, route outputs via structured logging (JSON stdout → Cloud Logging → Cloud Monitoring alerts), Pub/Sub, or tool-based integrations (email, Jira, Slack).

**Before implementing an ambient agent, clone and study the production sample** — it covers trigger wiring, middleware, structured logging, and Terraform. Look it up in the topic index in `references/samples.md`. [Full docs](https://adk.dev/runtime/ambient-agents/).

## 13. Managed Agents (server-hosted, first-party)

> **Requires ADK ≥ 2.4.0.** `ManagedAgent` connects to Google's first-party, server-hosted agents (e.g. the Antigravity agent) via the Managed Agents API: reasoning, tools, and execution all run in Google's managed environment, so there's no local sandbox to provision. It's a `BaseAgent`, so a standard `Runner` runs it like any other agent.

### When to use it

- **Managed agent** — powerful out-of-the-box capabilities (server-side web search, code execution) without operating the environment yourself. Trade-off: predefined server-side toolset, no client-side tools, runs only in the managed environment.
- **`LlmAgent` (§2)** — when you need control over the model, instructions, custom/MCP tools, or where execution happens.

### Setup

Two backends — satisfy the prerequisites for whichever you use, then supply an `agent_id`:
- **Gemini API:** set `GEMINI_API_KEY`. Use an out-of-the-box id (e.g. `antigravity-preview-05-2026`) or create your own (see below).
- **Agent Platform (GEAP, formerly Vertex):** authenticate with ADC (`gcloud auth application-default login`). The Managed Agents API is served only from the `global` location, and `ManagedAgent` enforces it.

### Create & use

```python
from google import genai
from google.adk.agents import ManagedAgent
from google.adk.tools import google_search

# Create your own agent (google-genai SDK, NOT ADK — ManagedAgent has no create()).
# Get-or-create keeps it idempotent; or skip entirely and use an out-of-the-box id like "antigravity-preview-05-2026".
client = genai.Client()
if "researcher" not in {a.id for a in (client.agents.list().agents or [])}:  # id must be unique, no gemini-/google-/... prefixes
    client.agents.create(
        id="researcher", base_agent="antigravity-preview-05-2026",
        system_instruction="Answer with fresh, grounded info from the web.",
    )

# Connect + use. A ManagedAgent is a BaseAgent: set it as root_agent, drop it in a
# workflow, or wrap it as AgentTool. Only server-side tools are allowed.
managed = ManagedAgent(
    name="researcher", agent_id="researcher",
    environment={"type": "remote"},        # tools run in the managed sandbox
    tools=[google_search],                 # or types.Tool(code_execution=types.ToolCodeExecution())
)
```

### Limits

- **Client-side tools raise `NotImplementedError`:** Python functions/callables and client-side MCP (`McpToolset`). Server-side tools work — ADK built-ins, raw `types.Tool` configs, and server-side remote MCP via `RemoteMcpServer`.
- **Backends differ:** the Gemini API and GEAP behave slightly differently today — test against your target backend.

Docs: [Gemini API agents](https://ai.google.dev/gemini-api/docs/agents) · [Agent Platform managed agents](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/managed-agents) · [Interactions API](https://ai.google.dev/gemini-api/docs/interactions-overview) · [building custom agents](https://ai.google.dev/gemini-api/docs/custom-agents). Samples: [basic](https://github.com/google/adk-python/tree/main/contributing/samples/managed_agent/basic), [code execution](https://github.com/google/adk-python/tree/main/contributing/samples/managed_agent/code_execution).

Pass the imported tool directly to `tools=[load_web_page]`, not `tools=[load_web_page.load_web_page]`.

### Factory Functions for Sub-agents

Use factory functions (not module-level instances) to avoid "agent already has a parent" errors. Always **call** the factory — passing the function reference fails with `ValidationError: Input should be a valid dictionary or instance of BaseAgent`.

```python
def create_researcher():
    return Agent(name="researcher", ...)

root_agent = SequentialAgent(
    sub_agents=[create_researcher(), create_analyst()],  # call the functions!
    ...
)
```

Data flows between sequential sub-agents via conversation history and `output_key` state.

# ADK Workflow API Cheatsheet

> Requires `google-adk >= 2.0.0`. Python only.
> Requires **Python >= 3.11**. The `Workflow` class itself does not support Live Streaming (`Runner.run_live`) — the graph engine needs strict control over event emission. Use a plain `Agent` for live/bidi flows. ADK 2.0 itself still ships `Runner.run_live` and `LiveRequestQueue`.

**Official docs:** [Workflows overview](https://adk.dev/workflows/index.md) ·
[Graph routes](https://adk.dev/graphs/routes/index.md) ·
[Collaboration](https://adk.dev/workflows/collaboration/index.md) ·
[Data handling](https://adk.dev/graphs/data-handling/index.md) ·
[Dynamic workflows](https://adk.dev/graphs/dynamic/index.md) ·
[Human-in-the-loop](https://adk.dev/graphs/human-input/index.md)

## 1. Core Concepts

A `Workflow` is a graph-based agent: nodes do work, edges define flow, `START` is the entry point.

```python
from google.adk.workflow import Workflow

def greet(node_input: str) -> str:
  return f"Hello, {node_input}!"

root_agent = Workflow(
    name="greeter",
    edges=[('START', greet)],
)
```

Three building blocks: **Nodes** (functions, LLM agents, tools), **Edges** (connections with optional route conditions), **START** (built-in entry receiving user input).

### Workflow Constructor

```python
root_agent = Workflow(
    name="my_workflow",
    edges=[...],                # Edge definitions (or use graph= instead)
    description="",             # Agent description
    input_schema=None,          # Pydantic model for input validation
    output_schema=None,         # Pydantic model for the workflow's output
    state_schema=None,          # Pydantic model for state validation
    rerun_on_resume=True,       # Rerun workflow on resume (default: True)
    max_concurrency=None,       # Limit parallel node execution (None = no limit)
    retry_config=None,          # Default RetryConfig applied to nodes
    timeout=None,               # Whole-workflow timeout in seconds
    wait_for_output=False,      # Wait for dynamically scheduled child output
)
```

---

## 2. Node Types

Any "NodeLike" is accepted in edges and auto-wrapped:

| Python Object | Wrapped As | Default `rerun_on_resume` |
|--------------|-----------|------------------------|
| Function/callable | `FunctionNode` | `False` |
| `LlmAgent` | Internal `_LlmAgentWrapper` | `True` |
| Other `BaseAgent` | Internal `AgentNode` | `False` |
| `BaseTool` | Internal `_ToolNode` | `False` |
| `BaseNode` subclass | Used as-is | Per subclass |

> **Auto-wrapping is the recommended approach.** Place functions, agents, and tools directly in edges — the framework wraps them automatically. You do not need to import or use internal wrapper classes directly.

---

## 3. Function Nodes

Most common node type. Parameter resolution:

| Parameter | Source |
|-----------|--------|
| `ctx` | Workflow `Context` object |
| `node_input` | Output from predecessor node |
| Any other name | `ctx.state[param_name]` |

```python
from google.adk.agents.context import Context

def process(ctx: Context, node_input: Any, user_name: str) -> str:
  # node_input = predecessor output; user_name = ctx.state['user_name']
  # START outputs types.Content (not str) unless input_schema is set
  return f"{user_name}: {node_input}"
```

### Return Types

- **Value** -> wrapped in `Event(output=value)`, triggers downstream
- **`None`** -> no event emitted, no downstream trigger
- **`Event`** -> used directly (for routing or state updates)
- **Generator** -> yield multiple events; only the last with `output` triggers downstream

```python
from google.adk.events.event import Event

def classify(node_input: str):
  if "urgent" in node_input:
    return Event(output=node_input, route="urgent")
  return Event(output=node_input, route="normal", state={"processed": True})
```

### Auto Type Conversion

FunctionNode auto-converts `dict` inputs to Pydantic models based on type hints. Works for `list[Model]` and `dict[str, Model]` too.

### `node_input` Type by Predecessor

| Predecessor | `node_input` Type |
|-------------|-------------------|
| Function returning `str`/`dict` | `str`/`dict` |
| Function returning `Event(output=X)` | type of `X` |
| `LlmAgent` (no `output_schema`) | `types.Content` |
| `LlmAgent` (with `output_schema`) | `dict` |
| `JoinNode` | `dict[str, Any]` (keyed by predecessor names) |
| `ParallelWorker` | `list` |
| `START` (no `input_schema`) | `types.Content` |
| `START` (with `input_schema`) | parsed schema type |

### @node Decorator & Explicit FunctionNode

```python
from google.adk.workflow import node, FunctionNode, RetryConfig

@node
def my_func(node_input: str) -> str:
  return node_input

@node(name="custom", rerun_on_resume=True)
async def my_async(node_input: str) -> str:
  return node_input

# Explicit FunctionNode for full control (func is keyword-only)
fn = FunctionNode(
    func=my_func,
    retry_config=RetryConfig(max_attempts=3),
    timeout=30.0,                          # Seconds before timeout
    parameter_binding='state',             # 'state' (default) or 'node_input'
    auth_config=None,                      # Requires rerun_on_resume=True
    state_schema=None,                     # Pydantic model for state validation
)
```

---

## 4. Edge Patterns

```python
# Sequential chain
edges = [('START', a), (a, b), (b, c)]

# Conditional routing (node returns Event with route=)
edges = [
    ('START', classifier),
    (classifier, success_handler, "success"),
    (classifier, error_handler, "error"),
    (classifier, fallback_handler, '__DEFAULT__'),  # Fallback route
]

# Fan-out (parallel branches)
edges = [('START', (branch_a, branch_b, branch_c))]

# Fan-in with JoinNode
from google.adk.workflow import JoinNode
join = JoinNode(name="merge")
edges = [((branch_a, branch_b), join), (join, final)]
# JoinNode output: {"branch_a": output_a, "branch_b": output_b}

# Looping (must have at least one routed edge — unconditional cycles rejected)
edges = [
    ('START', process),
    (process, check),
    (check, process, "continue"),
    (check, finish, "exit"),
]
```

Route values: `str`, `bool`, `int`. Multi-route fan-out: `return Event(output=x, route=["a", "b"])`. Edge matching multiple routes: `(node, target, ["route_x", "route_y"])`.

---

## 5. LLM Agent Nodes

Use `google.adk.agents.LlmAgent` in workflow edges — auto-wrapped internally, emits `Event(output=...)` for downstream data passing.

```python
from google.adk.agents import LlmAgent
from pydantic import BaseModel

class DraftOutput(BaseModel):
  title: str
  content: str

writer = LlmAgent(
    name="writer",
    model="gemini-3.7-flash",
    instruction="Write a draft based on the user's request.",
    output_schema=DraftOutput,  # Always set for structured output
    output_key="draft",         # Also store in state['draft']
)

agent = Workflow(
    name="pipeline",
    edges=[('START', writer), (writer, process_draft)],
)
```

**Always use `output_schema`** (Pydantic model) on LLM agents in workflows. Without it, output is `types.Content` which may cause type errors in downstream function nodes or serialization failures with JoinNode/database sessions.

## 6. Parallel Processing

### ParallelWorker — process list items concurrently

```python
from google.adk.workflow import node

@node(parallel_worker=True)
def process_item(node_input: int) -> int:
  return node_input * 2

# Input: [1, 2, 3] -> Output: [2, 4, 6]
agent = Workflow(
    name="parallel",
    edges=[('START', split_input), (split_input, process_item), (process_item, collect)],
)
```

Workers named `{parent_name}@{index}`. Input must be a list. Output is a list in same order.

### Fan-Out / Fan-In — diamond pattern

```python
from google.adk.workflow import JoinNode
join = JoinNode(name="merge")
edges = [
    ('START', splitter),
    (splitter, (branch_a, branch_b)),
    ((branch_a, branch_b), join),
    (join, combiner),  # combiner receives {"branch_a": ..., "branch_b": ...}
]
```

## 7. Human-in-the-Loop (HITL)

HITL is a general ADK feature (app-level `ResumabilityConfig`, the `request_input` tool, `resume_inputs`) — see `adk-python.md` "Human-in-the-Loop". Inside a workflow it works per node: a node yields `RequestInput` and reads replies from `ctx.resume_inputs` (keyed by `interrupt_id`).

```python
from google.adk.events.request_input import RequestInput

async def multi_step(ctx: Context, node_input: str):
  if not ctx.resume_inputs:
    yield RequestInput(interrupt_id="ask_name", message="Name?")
    return
  if "ask_email" not in ctx.resume_inputs:
    yield RequestInput(interrupt_id="ask_email", message="Email?")
    return
  yield Event(output={"name": ctx.resume_inputs["ask_name"],
                      "email": ctx.resume_inputs["ask_email"]})
```

**Node resume behavior:** `rerun_on_resume=False` (default FunctionNode) → the user's response becomes the node output; `rerun_on_resume=True` (default LlmAgent) → the node reruns with `ctx.resume_inputs` populated. **In loops:** use a unique `interrupt_id` per iteration (e.g. `f'review_{count}'`) to avoid infinite restarts.

## 8. State & Events

### Context Properties

```python
from google.adk.agents.context import Context

def my_node(ctx: Context, node_input: str) -> str:
  ctx.state.get("key", "default")   # Read state
  ctx.session.id                     # Session ID
  ctx.node_path                      # "Workflow/node_name"
  ctx.node                           # Current node
  ctx.run_id                         # Current execution ID
  ctx.attempt_count                  # 1 on first attempt (1-based)
  ctx.resume_inputs                  # HITL resume data (dict keyed by interrupt_id)
  ctx.interrupt_ids                  # Active interrupt IDs
  ctx.output                         # Node's result value (settable)
  ctx.route                          # Routing value (settable)
  return "result"
```

### Dynamic Node Scheduling

```python
async def orchestrator(ctx: Context, node_input: list) -> list:
  results = []
  for i, item in enumerate(node_input):
    result = await ctx.run_node(process_item, node_input=item)
    results.append(result)
  return results
```

`ctx.run_node()` requires `rerun_on_resume=True` on the calling node. Use `use_as_output=True` to delegate the node's output to the dynamic child.

### Event Fields

| Field | Type | Description |
|-------|------|-------------|
| `output` | `Any` | Output data for downstream nodes (must be JSON-serializable) |
| `route` | `str\|bool\|int\|list` | Routing signal for conditional edges (sets `actions.route`) |
| `state` | `dict` | State delta to apply (sets `actions.state_delta`) |
| `content` | `types.Content` | Content for web UI display |
| `message` | `ContentUnion` | Alias for content (auto-converted) |

### State: Prefer Event over ctx.state

```python
# Preferred — persisted in event history, replayable
def save(node_input: str):
  return Event(output=node_input, state={"key": node_input})

# Avoid — side effect, may be lost on replay
def save(ctx: Context, node_input: str) -> str:
  ctx.state["key"] = node_input
  return node_input
```

### Data Serialization Rules

- `Event.output` must be JSON-serializable. BaseModel returns auto-converted via `model_dump()`.
- `output_key` stores dicts (not BaseModel instances) — `validate_schema()` -> `model_dump()`.
- `ctx.state.get(key)` returns a dict. Use `MyModel(**data)` to reconstruct typed access.

## 9. Retry Configuration

```python
from google.adk.workflow import FunctionNode, RetryConfig

node = FunctionNode(
    func=flaky_call,           # func is keyword-only
    retry_config=RetryConfig(
        max_attempts=5,        # Default: None (treated as 5); 1 = no retry
        initial_delay=1.0,     # Seconds before first retry
        max_delay=60.0,        # Max seconds between retries
        backoff_factor=2.0,    # Delay multiplier per attempt
        jitter=1.0,            # Randomness factor (0.0 = none)
        exceptions=None,       # Exception types to retry (None = all)
    ),
)
```

Delay formula: `min(initial_delay * backoff_factor^attempt, max_delay) * (1 + random(0, jitter))`

## 10. Testing

> **Note:** The testing utilities below (`testing_utils`, `InMemoryRunner`) are internal to the ADK repository. They are not part of the public `google-adk` package. For your own tests, use `App` + `InMemoryRunner` from `google.adk.runners` or write a custom test harness.

```python
import pytest
from google.adk.workflow import Workflow
from google.adk.apps import App
from google.adk.runners import InMemoryRunner
from google.genai import types

@pytest.mark.asyncio
async def test_workflow():
  def step(node_input: str) -> str:
    return "done"

  agent = Workflow(name="test", edges=[('START', step)])
  app = App(name="test_app", root_agent=agent)
  runner = InMemoryRunner(app=app)

  session = await runner.session_service.create_session(
      app_name="test_app", user_id="test_user"
  )
  async for event in runner.run_async(
      user_id="test_user",
      session_id=session.id,
      new_message=types.Content(role="user", parts=[types.Part.from_text(text="hello")]),
  ):
    if event.output is not None:
      assert event.output == "done"
```

## 12. Best Practices

### Use Pydantic Models, Not Raw Dicts

Always define `BaseModel` classes for node I/O, LLM `output_schema`, and structured data:

```python
# Wrong: raw dicts
def lookup(node_input: dict[str, Any]) -> dict[str, Any]:
  return {"cost": 500}

# Correct: typed schemas
class FlightInfo(BaseModel):
  cost: int
  details: str

def lookup(node_input: Itinerary) -> FlightInfo:
  return FlightInfo(cost=500, details="Economy")
```

### Emit Content Events for Web UI

`event.output` is internal — only `event.content` renders in the ADK web UI:

```python
from google.genai import types

def final_output(node_input: str):
  yield Event(content=types.Content(role='model', parts=[types.Part.from_text(text=node_input)]))
  yield Event(output=node_input)
```

LLM agents emit content events automatically. Add them explicitly for function nodes with user-facing results.

### Agent Directory Convention

```
my_workflow/
  __init__.py    # from . import agent
  agent.py       # root_agent = Workflow(...)
```

### Advanced Patterns

- **Nested workflows**: A `Workflow` can be used as a node in another workflow
- **Dynamic node scheduling**: Use `await ctx.run_node(func, node_input=item)` at runtime (requires `rerun_on_resume=True`)
- **Custom Node subclass**: Subclass `Node`, implement `run_node_impl(*, ctx, node_input)` -> `AsyncGenerator`. Supports `parallel_worker=True` flag.
- **Custom BaseNode**: Subclass `BaseNode`, implement `_run_impl(*, ctx, node_input)` -> `AsyncGenerator`

### Graph Validation Rules

1. START must exist and have no incoming edges
2. All non-START nodes must be reachable
3. No duplicate node names or edges
4. At most one `__DEFAULT__` route per node
5. No unconditional cycles (cycles need at least one routed edge)

# Agent Infrastructure & Terraform Deployment

## Deployment Architecture

Agent Engine deployments follow a **Terraform-first, container-based deployment** model:
1. The project includes a minimal, standard `Dockerfile` based on `python:3.11-slim` that copies dependencies, installs `requirements.txt`, and runs native `adk api_server`:
   ```dockerfile
   FROM python:3.11-slim
   WORKDIR /app
   ENV PYTHONUNBUFFERED=1 PYTHONDONTWRITEBYTECODE=1 PORT=8080
   COPY requirements.txt .
   RUN pip install --no-cache-dir -r requirements.txt
   COPY . .
   EXPOSE 8080
   CMD ["adk", "api_server", "--host=0.0.0.0", "--port=8080", "."]
   ```
2. Cloud Build builds the Docker image and pushes it to Google Cloud Artifact Registry (`{region}-docker.pkg.dev/{project_id}/agents/{agent_name}:{tag}`).
3. Terraform provisions all required cloud infrastructure via `google_vertex_ai_reasoning_engine` with `spec.container_spec.image_uri`, along with dedicated Service Accounts, IAM role bindings (`roles/aiplatform.user`, `roles/logging.logWriter`), and trigger resources (such as Pub/Sub topics and subscriptions for event ingestion).

## State & Metadata Persistence
Deployment resource state (`deployedResourceId`, `serviceUrl`, `consoleUrl`, `deployedAt`) is stored directly in the `.agent` flow document inside the `"deployment"` block. Generated source code directories remain clean, isolated, and free of redundant sidecar JSON metadata files.

## CI/CD Differences from Cloud Run

| Aspect | Agent Runtime | Cloud Run |
|--------|-------------|-----------|
| **Build** | Dockerfile → image (built by Agent Engine) | Dockerfile → image (`gcloud builds`) |
| **Deploy command** | `agents-cli deploy` | `gcloud run deploy --image ...` |
| **Artifact** | Container image | Container image in Artifact Registry |
| **Python version** | Configurable in Dockerfile | Configurable in Dockerfile |
| **Load testing** | Via `locust` against Agent Runtime endpoint | Direct HTTP to Cloud Run URL |

`--mode` is required with `--url`: use `adk` for the ADK streaming API (`:streamQuery`) or `a2a` for the A2A protocol. Add `-v` for full JSON event payloads. Auth is auto-detected via Google Cloud credentials.

## Session & Artifact Services

Agent Runtime always uses in-memory sessions at scaffold time; at runtime `app_utils/services.py` upgrades to `VertexAiSessionService` when Agent Engine injects `GOOGLE_CLOUD_AGENT_ENGINE_ID`.

Artifacts use `GcsArtifactService` when `LOGS_BUCKET_NAME` is set, otherwise `InMemoryArtifactService`.

Environment variables set during deployment come from `agents-cli deploy` (the CLI's `deploy/agent_runtime.py`) for SDK deploys, and from `deployment/terraform/single-project/service.tf` (or the `cicd/` variant) for Terraform-managed deploys. Check those for current values.

### Memory Bank

To enable cross-session memory on Agent Runtime, configure `memory_bank_config` via `context_spec`. See the [`cross-session-memory` recipe](https://github.com/google/adk-samples/tree/main/core/python/cross-session-memory) for the full pattern.

## Networking (PSC Interface)

Agent Runtime cannot reach your VPC by default. To enable private connectivity, create a [network attachment](https://cloud.google.com/vpc/docs/create-manage-network-attachments) and deploy with `--network-attachment`. Add `--dns-peering-domain`, `--dns-peering-project`, and `--dns-peering-network` if you need private DNS resolution. PSC config is immutable after deployment — delete and redeploy to change it. See the [GCP docs](https://cloud.google.com/gemini-enterprise-agent-platform/scale/runtime/private-service-connect-interface) for prerequisites and setup.

### 1. A2UI Integration (`a2uiConfig`, TASK-221)
- If an agent node (root agent or any sub-agent) defines `a2uiConfig` with `enabled: true`:
  * Generate root-level `a2ui_components.py` (never create a separate `a2ui/` subfolder) with UI component definitions (`build_a2ui_surface` returning `{"messages": [{"createSurface": {"surfaceId": ..., "catalog": "gemini_enterprise_composite_v09", "title": ...}}, {"updateComponents": {"surfaceId": ..., "rootId": ..., "components": [...]}}, {"updateDataModel": {"surfaceId": ..., "data": {...}}}]}`).
  * **CANONICAL A2UI v0.9.1 COMPONENT CATALOG & JSON SCHEMA (MANDATORY)**:
    - Every component in `"components": [...]` MUST use the exact keys `{"id": "...", "component": "<WidgetName>", "properties": {...}, "children": ["child_id_1", ...]}` (use `"properties"`, NOT `"props"`).
    - **Supported Catalog Widgets**:
      1. **Layout & Containers**: `MaterialCard` (`title`, `subtitle`, `status`, `children`), `MaterialColumn` (`spacing`, `children`), `MaterialRow` (`spacing`, `children`), `MaterialGridList` (`columns`, `children`), `MaterialExpansionPanel` (`title`, `expanded`, `children`), `MaterialTabs` (`tabs: [{"id", "label"}]`, `children`), `MaterialDivider`, `MaterialDialog` (`title`, `children`).
      2. **Content & Status**: `MaterialText` (`text`, `variant`: `"h1"|"h2"|"h3"|"subtitle1"|"body1"|"body2"|"caption"|"code"`), `MaterialBadge` (`text`, `color`: `"success"|"warning"|"error"|"info"|"primary"|"neutral"`), `MaterialIcon` (`iconName`, `color`), `MaterialProgressBar` (`label`, `value`, `max`), `MaterialProgressSpinner` (`label`).
      3. **Data Display & Composite**: `MaterialTable` / `RichTable` (`title`, `columns`: `[{"field": "...", "headerName": "..."}]`, `rows`: `[{...}]`), `Stepper` (`activeStep`, `steps`: `[{"id", "title", "status"}]`), `WorkOrderList` (`title`, `items`: `[{"id", "title", "assignee", "priority"}]`), `VegaChart` (`title`, `description`, `spec`: Vega-Lite v5 JSON spec), `GoogleMap` (`title`, `center`: `{"lat", "lng"}`, `zoom`, `markers`: `[{"id", "title", "lat", "lng", "status"}]`), `MosaicCarousel` (`title`, `items`: `[{"id", "title", "subtitle", "description", "badge", "imageUrl", "actionLabel", "actionName"}]`).
      4. **Two-Way Bound Form Inputs & Actions**:
         - `MaterialInput`: `{"label": "...", "inputType": "text"|"number", "placeholder": "...", "value": {"path": "/form/fieldName"}}`
         - `MaterialSelect`: `{"label": "...", "options": [{"label": "Display Label", "value": "val"}], "value": {"path": "/form/fieldName"}}`
         - `MaterialSlider`: `{"label": "...", "min": 0, "max": 100, "step": 1, "value": {"path": "/form/fieldName"}}`
         - `MaterialCheckbox`: `{"label": "...", "checked": {"path": "/form/flagName"}}`
         - `MaterialSlideToggle`: `{"label": "...", "checked": {"path": "/form/flagName"}}`
         - `MaterialRadioButton`: `{"label": "...", "options": [{"label": "...", "value": "..."}], "value": {"path": "/form/fieldName"}}`
         - `MaterialButton`: `{"label": "...", "variant": "contained"|"outlined", "color": "primary"|"success"|"warning"|"error", "action": {"event": {"name": "action_name", "context": {"fieldName": {"path": "/form/fieldName"}}}}}`
  * **TOOL-LEVEL SURFACE EMISSION**: Whenever a tool function (in `tools/*.py`) supports an A2UI-enabled agent or sub-agent, include `"surface": build_..._surface(...)` in the dictionary returned by the tool function so the runner automatically renders the interactive A2UI surface whenever the tool is called.
  * **TOKEN BUDGET & SURFACE ATTACHMENT RULE**: Always set `max_output_tokens=8192` on all A2UI-enabled agents and sub-agents (never `1024` or `2048`, which truncate JSON mid-stream). In each agent's `instruction`, instruct the LLM to provide a clear, concise consumer-friendly markdown summary and business rationale, and NOT to manually re-type or dump the raw `"surface"` JSON dictionary from the tool output into its text response (because the runtime automatically extracts and attaches the lossless `"surface"` dict from the tool response).
  * Generate root-level `a2ui_adaptor.py` importing from `a2ui_components` and implementing UI action handlers (`A2uiAdaptor.route_user_action`) and `session.state` conversions. `A2uiAdaptor.route_user_action` MUST accept `(cls, user_action=None, session_state=None, context=None, **kwargs)` (supporting `action_name`, `action_or_prompt`, `user_action`, `prompt`, `action`, `session_state`, and `state` keyword arguments) and is synchronous. It MUST ONLY return `{"status": "handled", "surface": ..., "message": ...}` for structured `{"userAction": ...}` JSON payloads (e.g. button clicks) or exact single-word utility commands (`"help"`, `"about"`, `"show_skills"`, `"feedback"`, `"bug"`), and return `None` for normal conversational queries so the LLM agent and its tools execute normally.
  * **CRITICAL CONSUMER UI RENDERING RULE**: The Chat Runner renders interactive A2UI widgets by extracting ```` ```a2ui\n<JSON>\n``` ```` blocks from the tool response or callback response.
  * **FORBIDDEN**: NEVER instruct or allow the agent to output code tutorials, JSON schema explanations, or ASCII art representations of badges, progress bars, tables, or forms. Always render the real interactive A2UI surface from a consumer's perspective.
  * Attach `before_model_callback=a2ui_before_model_callback` on the root agent AND on every sub-agent that has `a2uiConfig.enabled == true` so incoming `{"userAction": ...}` payloads and deterministic surface commands are routed via `A2uiAdaptor.route_user_action`:
    ```python
    async def a2ui_before_model_callback(
        callback_context: CallbackContext, llm_request: LlmRequest
    ) -> Optional[LlmResponse]:
        user_prompt = ""
        if llm_request.contents:
            for part in getattr(llm_request.contents[-1], "parts", []):
                if getattr(part, "text", None):
                    user_prompt += part.text + " "
        user_prompt = user_prompt.strip()
        routed = A2uiAdaptor.route_user_action(user_prompt, session_state=callback_context.state)
        if routed and routed.get("status") == "handled" and routed.get("surface"):
            msg = routed.get("message", "Here is the interactive A2UI surface:")
            text = f"{msg}\n\n```a2ui\n{json.dumps(routed['surface'])}\n```"
            return LlmResponse(
                content=genai_types.Content(role="model", parts=[genai_types.Part.from_text(text=text)])
            )
        return None
    ```
